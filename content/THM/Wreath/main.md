## 2.利用python的虚拟环境下载一个漏洞利用脚本

```bash
python -m venv 虚拟环境名字 #创建虚拟环境
source 虚拟环境名字/bin/active #初始化虚拟环境
pip install -r requirements.txt #下载脚本依赖
deactive #清除虚拟环境配置,不过需要手动清除目录
```
